# 智能合约审计

UXUY 核心合约由独立第三方安全机构审计，审计报告公开可查。

详情：[https://docs.uxuy.com/security/audit/](https://docs.uxuy.com/security/audit/)

## 资金安全

- **冷热钱包分离**：平台资金分别托管于热端资金库（Hot Vault）与冷端资金库（Cold Vault），详见 [合约与基础设施地址](./contracts-and-addresses.md)。
- **保险基金**：为极端行情下的强平穿仓风险提供缓冲，详见 [保险基金与自动减仓（ADL）](../perpetuals/insurance-fund-and-adl.md)。
