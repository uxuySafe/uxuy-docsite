# Аудит смарт-контрактов

Основные контракты UXUY прошли аудит независимых сторонних организаций по безопасности, отчёты об аудите общедоступны.

Подробнее: [https://docs.uxuy.com/security/audit/](https://docs.uxuy.com/security/audit/)

## Безопасность средств

- **Разделение горячих и холодных кошельков**: средства платформы хранятся отдельно в горячем хранилище (Hot Vault) и холодном хранилище (Cold Vault), подробнее см. [Адреса контрактов и инфраструктуры](./contracts-and-addresses.md).
- **Страховой фонд**: обеспечивает буфер против риска возникновения отрицательного баланса при ликвидации в условиях экстремального рынка, подробнее см. [Страховой фонд и автоматическое сокращение позиций (ADL)](../perpetuals/insurance-fund-and-adl.md).
